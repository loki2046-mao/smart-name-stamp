图片命名压字工具 · 使用说明
=================================

这个小工具会把每张图片的“文件名”自动压到图片上，
并尽量避开人脸和主体，放在画面比较干净的地方，
浅色背景用深色字、深色背景用浅色字，背景乱时自动加描边/阴影，
保证看得清。字体用的是开源的思源黑体（Noto Sans CJK，SIL OFL 协议），
可以放心商用，不侵权。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一、怎么用（Mac 和 Windows 通用）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 双击打开 App，会弹出一个小窗口。
2. 第①步：点“选择单张图片”或“选择整个文件夹”，挑出要处理的图。
3. 第②步：点“选择输出文件夹”，挑一个用来存结果的文件夹。
   （注意：输出文件夹不能和原图在同一个文件夹，避免覆盖原图。）
4. 第③步（可选）：
   - 美化文件名：把文件名里的下划线、多余空格整理成空格。
   - 文字底：背景复杂时自动加一层淡底（更清楚，推荐）；
     或只用描边+阴影（遮挡更轻）。
5. 点“开始处理”，下方进度条会走，处理完会自动打开输出文件夹。

处理完成后，输出文件夹里会有：压好字的图片、一张总览图
（_contact_sheet.jpg，方便一眼检查整批效果）、还有一份处理报告。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
二、Mac 第一次打开（重要）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

这个 App 没有花钱做苹果签名，所以第一次打开时，macOS 可能会提示
“无法打开，因为无法验证开发者”。这是正常的，按下面做一次即可，
以后就能直接双击打开：

  做法 A（最简单）：
  1. 解压后，在 App 图标上点【右键】（或按住 Control 点一下）。
  2. 选择菜单里的【打开】。
  3. 在弹出的提示里再点一次【打开】。
  以后双击就能正常用了。

  做法 B（如果做法 A 仍被拦）：
  打开【系统设置】→【隐私与安全性】，
  拉到底，会看到“已阻止 SmartNameStamp”的提示，
  点旁边的【仍要打开】，再确认一次即可。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
三、Windows 第一次打开
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 把收到的压缩包解压到任意文件夹。
2. 进入文件夹，双击 SmartNameStamp.exe。
3. 如果出现蓝色的“Windows 已保护你的电脑”提示：
   点【更多信息】→【仍要运行】即可。
   （同样是因为没有付费签名，软件本身没问题。）

注意：要把解压出来的“整个文件夹”一起保留，不要只把 .exe 单独拿出来，
否则它找不到旁边的运行文件。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
四、给制作者：怎么打包出安装包
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Mac 版（在 Mac 上）：
  在项目文件夹里运行：  bash build_mac.sh
  完成后得到：
    - dist/SmartNameStamp.app        （App 本体）
    - dist/图片命名压字-Mac.zip       （发给别人的压缩包）

Intel 芯片 Mac 版：
  在项目文件夹里运行：  bash build_mac_intel.sh
  完成后得到：
    - dist-intel/SmartNameStamp.app
    - dist-intel/图片命名压字-Mac-Intel.zip
    - dist-intel/图片命名压字-Mac-Intel.pkg

  注意：不要把 Apple Silicon 机器上打出的 dist/图片命名压字-Mac.zip
  发给 Intel Mac，它里面的可执行文件是 arm64，会提示不支持。

Windows 版（必须在一台 Windows 电脑上做，Mac 上无法生成）：
  1. 先装 Python 3.11：https://www.python.org/downloads/windows/
     安装时记得勾选 “Add python.exe to PATH”。
  2. 把整个项目文件夹拷到 Windows 上。
  3. 双击运行  build_windows.bat
  4. 完成后得到：dist\SmartNameStamp\  这个文件夹。
     把它压缩成 zip 发给别人即可，对方解压后双击 SmartNameStamp.exe。
